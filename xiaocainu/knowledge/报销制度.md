# 企业报销制度（2026 版）

> 适用对象：公司全体员工因公务发生的费用报销
> 解释权：财务部。本制度用于「小财」智能报销助手的政策咨询与合规预审。
> 提示：带【预审输出】字样的小节用于「小财」合规预审节点生成「合规结果 / 风险摘要」字段，普通政策咨询可忽略。

## 一、适用范围与基本原则

1.1 适用对象：本公司正式员工、试用期员工因公务发生的合理费用，按本制度申请报销；实习生、外包人员报销以双方协议或专项通知为准。
1.2 不予报销范围（含但不限于）：私人消费、家庭支出、与公司业务无关的费用；礼品（非业务伴手礼）、现金券、纯娱乐消费、罚款滞纳金、个人交通通勤、理财投资损失。
1.3 报销基本原则：①真实——费用真实发生；②合法——票据合规、用途合法；③相关——与公务直接相关；④事前审批优先——能事前审批的优先事前审批，事后补批从严。
1.4 关键定义：
- **公务费用**：为履行岗位职责、完成业务目标而发生的支出。
- **事前审批**：费用发生前在系统/书面提交《费用申请单》并完成审批。
- **票据状态**：有票（已取得合规发票）/ 无票（应取得但未取得）/ 未提（尚未明确）。
1.5 特殊人群：试用期员工额度同正式员工，但单笔 > 3000 元需直属负责人加签；实习生仅报实际公务票据，不享受餐补/通讯补贴。

## 二、报销大类与额度标准

### 2.1 差旅费

- **往返交通**：实报实销。标准：高铁/动车二等座、经济舱；超出标准须事前审批。自驾按公里补贴（见 2.9）或凭过路费+油费票据，不重复报交通费。
- **住宿费**（标准间，按城市分级，超标需事前审批）：
  - 一线城市（北京、上海、广州、深圳）：≤ 500 元/晚
  - 新一线及二线城市（成都、杭州、武汉等）：≤ 350 元/晚
  - 三线及以下城市：≤ 250 元/晚
  - 同性同住原则：同性别同行应合住，合住不突破单人标准上限。
- **差旅餐补**：100 元/人/天，按出差自然天数计算，无需发票；与业务招待费不重复享受。
- **出差市内交通**：≤ 100 元/天，需票据及起止地点说明。
- **签证/保险/行李托运**：凭票据实报；境外出差建议购意外险，保费 ≤ 200 元/次。
- **差旅单据清单**：交通票 + 住宿发票 + 行程单/出差审批；餐补无需票但需在系统勾选出差天数。

### 2.2 业务招待费

- **单次限额**：单次招待费 ≤ 2000 元（含 2000）；超过 2000 元须事前提交《招待审批单》并经总经理批准。
- **人均限额**：人均 ≤ 300 元/人。
- **陪餐人数**：内部陪餐人员不超过客人的 1/2，严禁无关人员列席。
- **场所要求**：须在正规经营场所，禁止高档会所、私人会所。
- **礼品/伴手礼**：单次 ≤ 500 元，需事前说明并登记受赠方；超 500 元按招待费超标流程。
- **必备材料**：合规发票
- 无事前审批或超出人均标准的，超标部分不予报销。

### 2.3 办公用品及低值易耗

- **低值易耗**（单价 < 2000 元、使用年限 < 1 年）：单笔 ≤ 5000 元，需发票及采购清单。
- **固定资产**（单价 ≥ 2000 元或使用年限 ≥ 1 年）：走资产采购流程，不在此通道。
- 单笔超过 5000 元走采购流程，不适用个人报销通道。

### 2.4 市内交通费（打车）

- 仅限加班（21:00 之后）或外出公干，实报实销，需票据及起止地点说明。
- 日常通勤交通不报销；同城短途优先公共交通。

### 2.5 通讯费

- 按月凭合规发票实报，标准 ≤ 200 元/月（管理岗可上浮至 300 元/月，以人事通知为准）。
- 私用部分（套餐内通话/流量）不单独报销。

### 2.6 培训与职业发展费

- 外部培训凭培训通知 + 发票报销；单笔 ≤ 3000 元部门负责人批，> 3000 元需部门负责人 + 财务双签。
- 公司指派培训由公司统一结算，个人垫付需附指派邮件。

### 2.7 市场推广 / 业务宣传费

- 单笔 ≤ 5000 元凭合同/发票/成果证明报销；> 5000 元须事前审批并附活动方案。
- 含线上推广、物料制作、展位费等，需体现业务转化或品牌目标。

### 2.8 加班餐补与误餐

- 21:00 后加班，≤ 50 元/次，需审批截图或打卡记录，每月上限 15 次。
- 外出公干误餐凭票据 ≤ 80 元/餐，每日上限 2 餐。

### 2.9 私车公用与车辆费

- 私车公用按 1.5 元/公里补贴（含油费），需登记起止里程与事由；或凭油费+过路费票据实报，二选一不重复。
- 停车费、违章罚款不报销。

### 2.10 团建与员工活动费

- 部门团建 ≤ 150 元/人/次，季度不超过 1 次，需参与名单与发票。
- 公司级活动由公司统一预算，不占个人报销额度。

## 三、票据要求（合规红线）

3.1 发票类型：国家税务局监制的增值税发票（电子/纸质普通或专用发票）；境外费用凭当地合规票据 + 翻译件。
3.2 抬头税号：发票抬头须为公司全称及统一社会信用代码（税号），错抬头一律退回。
3.3 时限：开票日期距报销提交日不得超过 30 天，过期票据不报（特殊情形见 3.6）。
3.4 电子发票查验与防重：电子发票须打印并附增值税发票查验平台截图；同一发票代码+号码禁止重复报销，财务系统自动查重，重复提交视为违规。
3.5 行程单/小票：机票需行程单或电子客票号；出租车票需显示起止地点；无地点小票需附说明。
3.6 票据丢失处理：发票遗失原则上不报；确因不可抗力丢失，凭支付记录+情况说明+负责人审批，按 80% 核报，且需补开票承诺。
3.7 替票/假票/虚开：视为严重违纪，按公司纪律制度处理并追究责任，涉及金额较大的移交司法机关。
3.8 不予报销票据：白条、收据（除税法允许的小额收据）、个人抬头发票、作废发票。

## 四、报销流程与时限

4.1 填单规范：须注明报销类型、金额、事由、票据状态（有票/无票）、费用日期、归属项目（如有）。
4.2 提交时限：费用发生后 30 天内须提交；逾期需附《超时说明》并经负责人批准。
4.3 审批链：部门负责人复核 → 财务审核 →（超授权额度）总经理审批 → 出纳打款。
4.4 审批授权额度（与合规预审联动）：
- 部门负责人：在对应类别标准内复核，不批超标项。
- 财务：审核票据与额度，单笔 ≤ 5000 元可放行。
- 总经理：招待费单次 > 2000 元、办公用品 > 5000 元、住宿超城市标准、培训 > 3000 元等超授权情形，须总经理事前/事后审批。
4.5 打款：财务审核通过后 5 个工作日内完成打款至工资卡。
4.6 借款与备用金：出差/大额采购可借备用金，借款上限 = 预估费用 × 1.1；返回后 7 日内核销，超期从未报销余额中扣回。
4.7 退回与补正：审核不通过件退回至申请人，注明原因；补正后重新提交，时限不顺延。
4.8 加急通道：紧急款项凭负责人标注"加急"，财务 1 个工作日内处理，但合规要求不降低。

## 五、常见合规风险（预审重点）

- **超标未审批**：金额超过对应类别上限且未走事前审批 → 高风险，退回补审批。
- **无票/缺票**：票据状态为"无票"或缺失关键票据 → 不通过（提交前阻断）。
- **招待费违规**：单次超过 2000 元无审批，或人均超过 300 元，或陪餐人数超标 → 风险。
- **票实不符**：报销类型与票据内容不一致（如用餐饮发票报办公用品）→ 风险。
- **时限超期**：开票或提交超过 30 天 → 需说明，否则不通过。
- **重复报销**：同一发票/行程单多次提交 → 高风险，直接驳回并问责。
- **拆分规避**：将单笔超授权费用拆分为多笔小额以绕过审批 → 风险，合并审查。
- **非公务用途**：票据真实但用途与公务无关 → 不通过。

## 六、合规结果 / 风险摘要 字段说明（小财预审输出）【预审输出】

「小财」在填单引导分支做合规预审时，会产出两个字段写入飞书表格：

- **合规结果**（飞书「合规结果」列）：取值仅 **通过 / 风险** 两种。
  - **通过**：完全符合本制度，无风险点。
  - **风险**：存在需关注 / 需审批项（如超标待批、超时、票实不符），仍允许提交，但需在「风险摘要」写清原因与后续动作。
  - 注：硬性不合规（无票 / 白条 / 超范围 / 非公务）在提交前由「小财」直接追问补全，不会以"不通过"写入表格；因此表格「合规结果」列只会出现 **通过 / 风险**。
- **风险摘要**（飞书「风险摘要」列）：一句话给审核人看的说明，建议格式 "<问题>：<处置 / 需审批人>"。合规结果为 通过 时可留空或写"无"。

### 合规结果 / 风险摘要 映射表（预审判定依据）

| 触发场景 | 合规结果 | 风险摘要 示例 |
| 业务招待费 单次 > 2000 元 | 风险 | 单次招待费超 2000 元，需总经理事前审批 |
| 业务招待费 人均 > 300 元 | 风险 | 人均超 300 元，超标部分不予报销 |
| 办公用品 单笔 > 5000 元 | 风险 | 超 5000 元，走采购流程，不适用个人报销 |
| 差旅住宿 超城市分级标准（如一线 > 500 / 晚） | 风险 | 一线城市住宿超 500 元/晚，需事前审批 |
| 培训费 单笔 > 3000 元 | 风险 | 超 3000 元，需部门负责人+财务双签 |
| 票据状态 = 无票 / 未提 | （提交前阻断，追问补全，不写入） | — |
| 开票或提交 距今日 > 30 天 | 风险 | 距开票超 30 天，需附情况说明 |
| 票实不符（类型与票据内容不一致） | 风险 | 报销类型与票据内容不一致，请核对 |
| 拆分规避审批 | 风险 | 疑似拆分超授权费用，合并审查 |
| 完全符合制度 | 通过 | 无 |

> 例：员工请客户吃饭花了 2600 元、有票 → 合规结果 = 风险，风险摘要 = "单次招待费超 2000 元，需总经理事前审批"；该单仍可提交，审核人看到摘要即知需走总经理审批。

## 七、审批权限与组织架构

- 审批按"谁受益、谁负责"原则归属业务负责人；跨部门费用由主导部门牵头。
- 预算内费用走常规链；预算外费用须先补预算追加审批，再走报销。
- 财务对用户提交的合规性负审核责任，但不替代业务负责人对真实性的判断。
- 总经理审批事项清单以本制度 4.4 为准，清单外不得越权审批。

## 八、特殊情形处理

8.1 跨部门 / 项目分摊：一笔费用涉及多项目，须注明分摊比例，由各项目负责人分别确认。
8.2 境外报销：凭当地合规票据 + 中文翻译；汇率按报销当月公司公布汇率。
8.3 临时出差：未事前审批的临时出差，返回后 3 日内补《出差说明》可正常报销。
8.4 不可抗力：因灾害/疫情等导致票据丢失或超时，凭官方证明按 3.6 处理。
8.5 退单重提：被退回件补正后重新提交，原时限不顺延，超 30 天按超时处理。

---

## 九、违规与问责

9.1 虚假报销：伪造票据、虚构事项，一经查实全额追回，记过处分，情节严重者解除劳动合同。
9.2 重复报销：同一凭证多次提交，追回款项并警告；再犯按虚假报销处理。
9.3 协助违规：审批人明知不实仍审批，连带问责。
9.4 审计：财务定期抽查，抽查比例不低于 10%；异常单据 100% 复核。

## 十、典型问答示例（供参考，不作为条款）

- 问：差旅费住宿上限多少？
  答：按城市分级，一线城市 ≤ 500 元/晚，二线 ≤ 350 元/晚，三线及以下 ≤ 250 元/晚，超标需事前审批；同性别同行应合住。
- 问：请客户吃饭花了 2600 元能报吗？
  答：单次招待费上限 2000 元，2600 元已超过且需总经理事前审批，否则超标部分不予报销，建议补《招待审批单》。小财预审会标 合规结果 = 风险、风险摘要 = "单次招待费超 2000 元，需总经理事前审批"。
- 问：没有发票能报销吗？
  答：不能。必须提供增值税发票，无票、白条、收据一律不报；确因不可抗力丢失凭支付记录+说明按 80% 核报。
- 问：报销提交后「合规结果」显示"风险"是什么意思？
  答：表示这笔单存在需关注项（如超额度待审批、超时），仍可进入审批流，但审核人会看到「风险摘要」里的具体原因，按提示补审批或说明即可。
- 问：出差餐补和招待费能同时报吗？
  答：不能重复。差旅餐补是按天的固定补贴（无需票），业务招待费是请客费用（需票+名单）；同一餐次只取其一。
- 问：私车公用怎么报？
  答：二选一——按 1.5 元/公里补贴（登里程）或凭油费+过路费票据实报，不重复；停车费、违章罚款不报。
- 问：超 30 天的发票还能报吗？
  答：原则上不报；确因特殊原因需附《超时说明》经负责人批准，且票据真实合规。
- 问：一笔费用涉及两个项目怎么分摊？
  答：注明分摊比例，各项目负责人分别确认，财务按确认比例入账。
